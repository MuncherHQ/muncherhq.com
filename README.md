# MuncherHQ

Landing page for [muncherhq.com](https://muncherhq.com) — an indie software studio building privacy-focused utility apps.

> Small Studio. Sharp Tools.

## Products

- **[FileMuncher](https://filemuncher.com)** — 40+ free browser-based file tools (PDF, image, video, audio, QR codes). Zero uploads, 100% client-side.
- **BetaMuncher** *(coming soon)* — Android app that finds open Google Play beta programs. Privacy-first, open source.

## Tech Stack

- Vanilla HTML/CSS/JavaScript — no framework, no build step
- Deployed on [Vercel](https://vercel.com)
- Analytics via Google Tag Manager

## Development

Just open `index.html` in a browser — no build step required.

For Vercel preview deployments:

```bash
vercel dev
```
