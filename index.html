Philosophy

How we build.

🔒

Privacy is non-negotiable

Your files stay on your device. Your data stays yours. We don't track, we don't snoop, we don't sell. If it can run locally, it does.

🔌

Open where it matters

Client code is open source. Server code protects the business. We're transparent about what runs on your device because you should be able to verify it.

🔨

Built by one, used by many

This is a one-person studio. No committees, no roadmap theater. Just a maker who ships tools they actually want to use.

🎯

Do one thing well

Each tool solves a real problem for power users. No feature creep, no dark patterns, no subscription gates on basic functionality.
